# AcadOS
AcadOS (Automated Proctor Scheduling and Academic Operations System) คือระบบบริหารจัดการงานวิชาการและจัดสรรตารางคุมสอบอัตโนมัติ พัฒนาด้วย Spring Boot ระบบมีจุดเด่นในการใช้อัลกอริทึมสุ่มจัดตารางแบบมีเงื่อนไข (Constraint-based Randomization) เพื่อป้องกันปัญหาตารางสอนหรือสอบชนกัน และช่วยกระจายภาระงานของบุคลากรอย่างเป็นธรรม
