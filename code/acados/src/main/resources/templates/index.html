4 สถานการณ์วิศวกรรมหลัก (Core Verified Scenarios)

สถาปัตยกรรมระบบได้รับการออกแบบและทดสอบครอบคลุมทุกวงจรการทำงาน

171 / 171 Tests Passed
Scenario 1: ลงทะเบียนเรียน

นักศึกษาลงทะเบียนในกลุ่มเรียนที่เปิดสอน ระบบป้องกันการลงซ้ำ ตรวจจับเวลาชน (Conflict) และจำกัดความจุ

Scenario 2: จัดตารางอัตโนมัติ

Engine คำนวณ 7 Hard Constraints จัดห้องและเวลาลงสถานะ DRAFT ให้ Admin ตรวจสอบก่อนสั่ง Publish

Scenario 3: ขอแลกคาบสอน

อาจารย์ยื่นขอแลกคาบ (PENDING) → อาจารย์คู่แลกตอบรับ (ACCEPTED) → Admin อนุมัติสลับตารางจริง (APPROVED)

Scenario 4: ยกเลิกกลุ่มเรียน

Admin ยกเลิกกลุ่มเรียน ระบบ Cascade ยกเลิกการลงทะเบียนของนักศึกษา ปลดคาบสอน และแจ้งเตือนทุกคน
