Operations · Scenario 3

อนุมัติคำขอแลกคาบสอน (Teacher Swap Review)

ตรวจสอบและอนุมัติคำขอแลกคาบสอนที่ผ่านการตอบรับ (ACCEPTED) จากอาจารย์คู่แลกแล้ว

บัญชีคำขอแลกคาบสอนในระบบ

(แสดงเฉพาะรายการรออนุมัติ)

วงจรชีวิตคำขอแลกคาบสอน (Scenario 3 Workflow)

1. สร้างคำขอ (PENDING)
อาจารย์ผู้ขอส่งคำขอแลกคาบ โดยระบบตรวจสอบ Conflict พื้นฐาน
2. ตอบรับคำขอ (ACCEPTED)
อาจารย์คู่แลกเข้าสู่ระบบและกดตอบรับคำขอ เพื่อส่งต่อให้ผู้ดูแลระบบ
3. อนุมัติขั้นสุดท้าย (APPROVED)
Admin กดอนุมัติ ระบบสลับตารางสอนจริงและส่งการแจ้งเตือนทั้งสองฝ่าย
